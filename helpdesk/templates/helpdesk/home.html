Project Abstract

The NCERC College Helpdesk is a Django web application that helps students and visitors find college information through a conversational interface. It uses a locally hosted Qwen language model with a lightweight retrieval layer to find relevant, verified campus facts. If the model is not available, the existing local rule-based chatbot remains as a fallback.

The available information covers departments, facilities, rooms, floors, and services. Answers can show the location details and facility images present in the data, with links to the official NCERC 360° campus tour and Google Maps for directions to the college. Users can rate answers, and feedback is stored in the project’s SQLite database.

The model runs locally through Ollama and does not require a paid AI service or an external AI API key. The assistant only provides details supported by its campus data; verified building-to-building routes, additional college timings, and policies must be added from authoritative college information before the system can answer those questions reliably.
